The tensorforge_autoload_top connects the operand loader to the matrix job pipeline. The host provides combinational row-major A/B memory ports and starts a matrix job; hardware handles each tile's loading, launch, writeback and advance. The INT8 regression checks a 5x33 times 33x5 matrix. The source memory interface assumes zero-cycle combinational read latency, not synchronous SRAM or AXI. The new integration test is subject to CI verification.
