The matrix_operand_loader_sync uses a two-phase REQUEST/WRITE transaction per byte to support a one-clock registered SRAM read. It zero-pads partial M/P output tiles and partial K blocks, and produces the same local operand bank addressing as the combinational loader. The source read data must be stable through the WRITE phase. This standalone loader is not yet selected by tensorforge_autoload_top; that integration is a future step.
